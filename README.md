# SenTox AI内容审核平台

SenTox AI内容审核平台是一个基于多智能体协作架构的下一代智能内容审核系统，集成了三项前沿研究成果：ICL-DiTox多智能体架构研究、SenTox-GLDA毒性检测模型以及TMuS-Toxgent情境学习集成技术。该平台通过多个专业化AI智能体的协同工作，为社交媒体、电商平台、新闻媒体和游戏社区等各类在线平台提供精准、高效的内容安全保障服务。

## 核心技术架构

整个平台的核心建立在多智能体系统之上，包含分类智能体、推理智能体和协调智能体三大核心组件。分类智能体负责使用自研的SenTox-GLDA模型进行初步毒性分类，该模型基于GLDA（全局-局部-差异注意力）算法，专门针对中文评论场景进行训练优化，在毒性检测任务中达到了92%的行业领先准确率。推理智能体则通过思维链推理机制对内容进行深度语义分析，识别隐含意义、上下文关联和潜在风险。协调智能体作为决策中枢，整合各智能体的分析结果，通过动作链执行和MCP多智能体通信协议达成最终共识，生成详细的审核报告和处置建议。

## 平台主页功能设计

平台主页承担着展示系统能力和引导用户体验的重要职责，通过数据驱动的方式实时展现系统的处理能力和技术优势。页面顶部的英雄区域突出强调了基于三大研究成果的技术底座，同时通过简洁明了的描述向用户传达多智能体协作为内容安全带来的革命性提升。系统统计模块实时展示内容提交总量、审核完成数量、活跃智能体数量和系统准确率等关键指标，这些数据不仅体现了平台的处理能力，更向潜在用户证明了系统的可靠性和成熟度。核心技术特性介绍部分通过卡片式布局详细阐述了多智能体协作、SenTox-GLDA模型和大模型集成三大技术优势，每个特性都配有具体的性能指标和应用价值说明，帮助用户快速理解平台的技术价值。

## 智能内容审核提交

内容审核提交页面是用户与多智能体系统交互的主要入口，设计简洁直观的同时功能强大。内容输入区域支持最大5000字符的文本内容，实时字符计数帮助用户控制输入长度，智能提示区域列举了社交媒体评论、用户生成内容、论坛帖子等支持的内容类型。平台选择功能允许用户指定内容来源，包括微博、抖音、微信、知乎、哔哩哔哩、小红书等主流社交媒体平台，系统会根据不同平台的用户行为特征和语言风格进行针对性优化审核。提交处理采用异步架构，用户提交内容后系统立即创建审核任务并返回任务ID，后台多智能体系统开始协作处理，通过SenTox-GLDA模型进行初步分类，随后各智能体基于思维链推理进行深度分析，最终生成包含决策结果、置信度评分、推理链条和智能体决策详情的综合审核报告。

平台内置了完善的系统监控和健康检查机制，通过实时监控各个组件的运行状态和性能指标确保服务的高可用性和稳定性。数据库连接监控定期检查SQLite数据库的连接状态和响应性能，监控数据库查询延迟、连接池使用率、存储空间占用等关键指标。SenTox-GLDA模型监控跟踪AI模型的加载状态、推理延迟、内存使用情况和预测准确率，当模型性能出现异常时会自动触发重新加载或降级处理机制。多智能体系统健康检查通过异步调用各智能体的状态接口验证其响应能力和协作效果，监控智能体间的通信延迟、决策一致性和系统吞吐量。外部依赖监控检查阿里云百炼API的可用性和响应速度，当外部服务出现问题时系统会自动切换到备用方案或降级服务模式。性能指标收集涵盖CPU使用率、内存占用、网络IO、磁盘IO等系统资源指标，以及业务层面的请求量、错误率、平均响应时间等关键业务指标，所有监控数据都会以JSON格式返回并支持与外部监控系统集成。

## 技术实现细节

整个平台基于Flask Web框架构建，采用模块化的蓝图架构设计确保代码的可维护性和扩展性。数据存储采用SQLAlchemy ORM框架配合SQLite数据库，支持用户管理、内容提交记录、审核历史等业务数据的持久化存储。用户认证系统集成Flask-Login扩展提供会话管理和权限控制功能，支持用户注册、登录、权限验证和会话保持。多智能体系统通过异步编程模型实现，使用asyncio库支持并发处理和智能体间的异步通信，每个智能体都继承自统一的BaseAgent基类并实现特定的决策逻辑。阿里云百炼大模型集成通过DashScope API实现，支持多种预训练语言模型的调用和自定义prompt工程。前端界面采用Bootstrap响应式框架设计，结合Font Awesome图标库和自定义CSS样式表提供现代化的用户界面体验。系统配置采用环境变量和配置类的方式管理，支持开发环境和生产环境的灵活切换，所有敏感信息如API密钥都通过环境变量注入确保安全性。

## 部署与运维指南

平台支持多种部署方式以适应不同的运维需求和环境约束。开发环境部署只需要Python 3.8+环境，通过pip安装requirements.txt中列出的依赖包即可快速启动开发服务器进行功能测试和开发调试。生产环境部署推荐使用Docker容器化部署，项目提供标准的Dockerfile和docker-compose.yml配置文件，支持一键部署和水平扩展。数据库迁移通过Flask-Migrate扩展管理，系统提供init_db.py和create_tables.py脚本支持数据库初始化和表结构创建。环境变量配置包括数据库连接字符串、阿里云API密钥、Redis连接地址等关键配置项，生产环境建议使用加密配置管理系统保护敏感信息。日志管理采用Python标准logging模块，支持多级别日志输出和文件轮转，便于问题排查和性能分析。系统监控建议集成Prometheus和Grafana构建完整的监控告警体系，通过自定义指标和仪表板实时掌握系统运行状态。负载均衡可以通过Nginx反向代理实现，支持多实例部署和自动故障转移，确保服务的高可用性。
