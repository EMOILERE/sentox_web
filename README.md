# SenTox AI Content Moderation Platform

SenTox AI Content Moderation Platform is a next-generation intelligent content moderation system based on a multi-agent collaborative architecture, integrating three cutting-edge research achievements: ICL-DiTox multi-agent architecture research, SenTox-GLDA toxicity detection model, and TMuS-Toxgent contextual learning integration technology. The platform provides accurate and efficient content security services for various online platforms such as social media, e-commerce platforms, news media, and gaming communities through the collaborative work of multiple specialized AI agents.

## Core Technical Architecture

The core of the entire platform is built upon a multi-agent system, comprising three core components: the Classification Agent, the Reasoning Agent, and the Coordination Agent. The Classification Agent is responsible for performing initial toxicity classification using the self-developed SenTox-GLDA model. This model is based on the GLDA (Global-Local-Difference Attention) algorithm, specifically trained and optimized for Chinese comment scenarios, achieving an industry-leading accuracy rate of 92% in toxicity detection tasks. The Reasoning Agent performs deep semantic analysis of content through a chain-of-thought reasoning mechanism, identifying implied meanings, contextual associations, and potential risks. The Coordination Agent acts as the decision-making hub, integrating the analysis results from various agents, reaching a final consensus through action chain execution and the MCP multi-agent communication protocol, and generating detailed moderation reports and disposal recommendations.

## Technical Implementation Details

The entire platform is built based on the Flask Web framework, adopting a modular blueprint architecture design to ensure code maintainability and scalability. Data storage uses the SQLAlchemy ORM framework with the SQLite database, supporting the persistent storage of business data such as user management, content submission records, and moderation history. The user authentication system integrates the Flask-Login extension to provide session management and permission control functions, supporting user registration, login, permission verification, and session persistence. The multi-agent system is implemented through an asynchronous programming model, using the asyncio library to support concurrent processing and asynchronous communication between agents. Each agent inherits from a unified BaseAgent base class and implements specific decision-making logic. The Alibaba Cloud Bailian large model integration is implemented through the DashScope API, supporting the invocation of various pre-trained language models and custom prompt engineering. The front-end interface is designed using the Bootstrap responsive framework, combined with the Font Awesome icon library and custom CSS stylesheets to provide a modern user interface experience. System configuration is managed using environment variables and configuration classes, supporting flexible switching between development and production environments. All sensitive information such as API keys is injected through environment variables to ensure security.

## Deployment and Operation Guide

The platform supports multiple deployment methods to adapt to different operational needs and environmental constraints. Development environment deployment only requires a Python 3.8+ environment. Quickly start the development server for functional testing and development debugging by installing the dependency packages listed in requirements.txt via pip. Production environment deployment recommends using Docker containerized deployment. The project provides standard Dockerfile and docker-compose.yml configuration files, supporting one-click deployment and horizontal scaling. Database migration is managed through the Flask-Migrate extension. The system provides init_db.py and create_tables.py scripts to support database initialization and table structure creation. Environment variable configuration includes key configuration items such as the database connection string, Alibaba Cloud API keys, and Redis connection address. It is recommended to use an encrypted configuration management system to protect sensitive information in the production environment. Log management uses the Python standard logging module, supporting multi-level log output and file rotation, facilitating problem troubleshooting and performance analysis. System monitoring is recommended to be integrated with Prometheus and Grafana to build a complete monitoring and alerting system, providing real-time insight into the system's operational status through custom metrics and dashboards. Load balancing can be achieved through an Nginx reverse proxy, supporting multi-instance deployment and automatic failover to ensure high service availability.
